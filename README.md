# Savage Showdown — Combat Lab 0.2
Replace index.html in the existing GitHub Pages repository root. The roster is embedded in HTML; roster.json is also included. No external dependencies. Use Play view and rotate phone. Controller support uses browser standard gamepad mapping; not hardware tested. Touch controls and move catalog remain available. Graphics are procedural 2D shaded illustrations, not real 3D models. Combat uses the original prototype timing and shared animations; individual frame data, full animation chains, original music and native releases are future work.
